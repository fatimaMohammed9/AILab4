?- house = house.
true.
Both terms are identical, so they can be unified.


?- house = abc.
false.
The two atoms are different, so they cannot be unified.

?- edge(a,b) = edge(C,b).
C = a.
The structures have the same name and number of arguments. Therefore, C is unified with a.

?- edge(a,d) = edge(C,B).
C = a,
B = d.
The corresponding variables are unified with the matching values: C = a and B = d.

- edge(C,B) = edge(a,d).
C = a,
B = d.
The variables are unified with the corresponding values in the second term.

?- edge(A,f(g,h)) = edge(a,B).
A = a,
B = f(g, h).
A is unified with a, and B is unified with the structure f(g,h).

?- edge(A,A) = edge(b,b).
A = b.
The same variable A appears twice, and both corresponding values are b, so A = b.

?-  A = B, B = f.
A = B, B = f.
A and B are unified, and then both become f.

?- A = B, B = f, A = e.
false.
A and B must have the same value, but B = f and A = e, so the terms conflict.

?- edge(A,A) = edge(b,c).
false.
The same variable A appears twice, so both values must be the same. However, b and c are different, so the terms cannot be unified.
